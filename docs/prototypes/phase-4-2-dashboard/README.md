# Phase 4.2 本地管理页原型

## 状态

- 产品状态：v2 核心流程验证通过。
- 验证日期：2026-08-11。
- 当前原型：[`dashboard-prototype-v2.html`](dashboard-prototype-v2.html)。
- 边界：这些文件只验证信息架构、交互和产品语义，不代表正式前端技术栈、HTTP/SSE 合同或安全实现已经确定。

## 已确认产品行为

- 第一屏先展示总体运行摘要，默认“今日”，可切换“本次会话 / 今日 / 最近 7 天”。
- 摘要包含任务总数、运行中、需处理、Token 消耗、任务耗时区间和 Token 构成；Token 缺失显示“— / 未上报”，不按零计算。
- 首页随后展示运行中、待审批和异常三个高优先级区域；历史任务放在独立列表页。
- 任务只显示阶段、当前步骤、最近事件、耗时和等待原因，不显示完成百分比。
- 点击任务打开右侧详情面板，先展示上下文、影响、建议和最近事件。
- 普通批准或拒绝可在详情面板完成；拒绝必须填写反馈。
- 拒绝只阻止当前方案或动作，任务携带反馈返回 Codex 重新规划；不得继续等价动作，越出原合同或权限的新路径必须再次审批。
- 重试、取消和清理需要显示作用范围与影响，并经过二次确认。
- 加载、空状态、接口错误、事件流重连和 Token 未上报均有独立反馈；重连期间禁止管理写操作。
- 页面不创建任务、不编辑 TaskContract；任务设计与下发继续由 Codex/MCP 完成。

## 原型版本

- `v0`：第一版运行与处置仪表盘。
- `v1`：加入总体运行摘要、时间范围、耗时区间和 Token 构成。
- `v2`：加入审批、拒绝反馈、高风险二次确认和异常/连接状态模拟；这是当前验证基线。

## 验证结论

用户完成了总体运行态、阶段识别、普通审批、拒绝理由校验、异常定位、高风险确认、Token 未上报，以及加载、空、错误和重连状态验证，并确认产品行为符合预期。拒绝审批的正式语义在验证后补充为“阻止当前方案并返回 Codex 重新规划”。

下一门槛是 PRD OQ-006：定稿 localhost 访问保护、同源/CSRF、HTTP/JSON + SSE Schema、游标与断线恢复、写操作幂等与并发、错误映射、脱敏、静态资源交付、自动打开浏览器边界和前端技术栈。关闭该门槛前不开始正式实现。
